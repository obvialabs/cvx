# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to **security@obvia.dev**. Do not open a public issue for an unpatched vulnerability.

Include enough information to reproduce and assess the problem when possible:

- affected CVX version or commit
- runtime and operating system
- minimal reproduction
- expected and observed behavior
- potential impact

Reports will be reviewed before coordinated public disclosure. Please avoid publishing exploit details until a fix or mitigation is available.

## Scope

Security reports may include package integrity, build/publish behavior, dependency-chain concerns, malformed-input behavior that creates a security boundary issue, or vulnerabilities in distributed artifacts.

Ordinary correctness bugs and performance regressions should use the public issue tracker instead.
